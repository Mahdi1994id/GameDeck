# 🎮 GameDeck

لانچر بازی سبک برای ویندوز — یک فایل EXE مستقل، بدون نصب و بدون وابستگی.

![GameDeck](GameDeck-icon-256.png)

> نسخهٔ فعلی: **v1.0.11**

## ✨ امکانات

- **کتابخانهٔ بازی** با استخراج خودکار آیکن بازی‌ها، دسته‌بندی، جستجو و مرتب‌سازی — نمایش تایل یا لیست
- **Launch Optimizer** — بستن برنامه‌های پس‌زمینه قبل از اجرای بازی برای آزادسازی رم و CPU:
  - 🔴 پروسه‌های سیستمی ویندوز و آنتی‌ویروس‌ها برچسب SYSTEM می‌گیرند، چک‌باکسشان قفل است و هرگز بسته نمی‌شوند
  - 🟠 موارد حساس (درایورها، نرم‌افزارهای ماوس/کیبورد، لانچرهای بازی) برچسب CAUTION و توضیح خطر دارند
- **Gaming Tweaks** — مجموعهٔ بهینه‌سازی‌های سیستمی برای گیمینگ
- **Play Stats** — آمار بازی: مدت و تعداد اجرا، آخرین زمان بازی
- **Game Mode و پلن برق High Performance** به‌صورت خودکار هنگام اجرای بازی (با بازگردانی خودکار بعد از خروج)
- **۴ رنگ اکسنت قابل انتخاب** در Settings (بنفش، رزی، آبی، نارنجی)
- آیکن اختصاصی و رابط تیرهٔ سبک — مصرف CPU در حالت بیکاری حدود صفر و رم حدود ۳۰–۶۰ مگابایت

## 📥 دانلود

از بخش [Releases](https://github.com/Mahdi1994id/GameDeck/releases) آخرین نسخهٔ `GameDeck.exe` را دانلود کنید (حدود ۱۰ مگابایت، تک‌فایل).

## 🚀 اجرا

نیازی به نصب نیست — فقط فایل را اجرا کنید. داده‌ها در `%AppData%\GameDeck` ذخیره می‌شوند.

اگر ویندوز SmartScreen هشدار داد: برنامه امضای دیجیتال ندارد؛ **More info → Run anyway** بزنید.

## 🔒 دربارهٔ سورس‌کد

سورس‌کد عمومی منتشر نمی‌شود؛ این ریپو فقط فایل اجرایی رسمی را ارائه می‌کند. لطفاً فایل exe را فقط از همین ریپو دانلود کنید.
